# agent-book

도서 관련 서점 페이지 검색과 독서 검색어 트렌드 앱입니다. 기본은 실제 검색 모드입니다.

## 현재 실제 데이터 연결

- 네이버 웹 검색: 교보문고·YES24·알라딘 검색 결과 중 상품 페이지 링크만 표시합니다. 제목/본문에 검색어가 포함된 결과를 남깁니다. 결과는 정규화된 도서 레코드가 아니며 중고·전자책·세트 등 서로 다른 상품이 포함될 수 있습니다.
- 네이버 데이터랩: 소설·에세이·자기계발·경제 경영·과학의 `분야 + 책 추천` 검색어 5개에 대해 최근 4개의 완결 주(월~일) 상대 검색량을 표시합니다. 없는 구간을 0으로 만들지 않습니다. 시장 전체 관심도나 판매순위가 아닙니다.
- 네이버 키는 Sites 비밀 환경변수로 등록합니다. 클라이언트 코드에는 포함되지 않습니다.
- YES24 공개 상품 페이지: 검색 결과 중 최대 4개 상품의 JSON-LD에서 동일 상품 ID와 유효한 ISBN을 확인하고 종이책 새 상품 판매가·재고를 수집합니다. robots.txt를 확인하고 요청 동시성은 2개, 페이지 크기와 타임아웃을 제한하며 성공 결과는 프로세스 메모리에 6시간 캐시합니다. 차단·오류·미지원 상품은 가격 없는 원문 링크로 유지합니다. 캐시는 인스턴스 재시작 시 초기화됩니다.
- 가격에 확인 시각과 출처를 표시합니다. 배송비·회원 혜택은 확인되지 않아 여러 서점의 최저가로 표시하지 않습니다. 예시 모드의 가격 비교는 가상 데이터입니다.

## API 종료에 따른 변경

## 실행 및 검증

Node 22.13+에서 `npm ci`, `npm run dev`로 실행합니다. 로컬 인증값은 Git에서 제외된 `.dev.vars`에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`으로 설정합니다. 배포에서는 Sites 환경변수를 사용합니다. 검색 및 데이터랩(검색어트렌드) API 사용 설정이 필요합니다.

`npm test`, `npx tsc --noEmit`, `npm run build`로 검증합니다.

`GET /api/books?q=...`는 1~100자 검색, `GET /api/trends`는 검색어 트렌드, `GET /api/status`는 키 설정 여부만 반환합니다. 검색 결과는 60초, 트렌드는 1시간 동안 서버 메모리에 캐시하며 최대 100개 항목을 유지합니다. 최근 검색은 사용자 브라우저에 최대 5개 저장됩니다.

## 구조

- `app/page.tsx`: 검색·상세·비교·트렌드 화면
- `lib/providers.ts`: 실제 API 호출, 도메인 필터링, 관심도 집계
- `lib/prices.ts`: YES24 공개 구조화 데이터 수집·robots 검사·캐시
- `lib/books.ts`: 예시 가격 비교, ISBN/URL 검증
- `lib/api.ts`: 서버 환경변수와 캐시
- `tests/`: 가격·ISBN·URL·공급자 실패·트렌드 기간 테스트

실제 API 키와 함께 도서 검색, 데이터랩 응답을 검증했습니다. 광범위한 UI 자동화 검증은 수행하지 않았습니다.

## 수집 가격 저장 및 갱신

배포 서버에서 YES24 페이지 수집이 실패하는 경우 로컬에서 실제 공개 상품 정보를 수집한 `data/prices.json`을 동일 상품 ID에 한해 사용합니다. 저장 가격은 확인 시각을 표시하고 7일이 지나면 가격 표시에서 제외합니다. 최초 데이터는 10개 검색어에서 수집한 26개 상품이며 전체 도서 가격을 포함하지 않습니다. 자동 정기 수집은 아직 설정하지 않았습니다.

환경변수에 네이버 인증값을 설정한 뒤 `node --experimental-strip-types scripts/collect-prices.mjs '소년이 온다' '채식주의자' ...`로 새로 수집하고 빌드·배포하면 저장 가격을 갱신합니다. 수집이 전부 실패하면 기존 파일을 덮어쓰지 않습니다. 검색 API와 데이터랩은 배포 서버에서 실시간으로 호출하며 앞서 명시한 캐시를 적용합니다.

## AI 맞춤 추천

`AI 맞춤 추천`에서 독서 취향(5~500자)과 분야를 입력합니다. 서버는 OpenAI Responses API로 검색어 최대 2개를 생성하고, 네이버의 실제 도서 상품 후보를 검색한 다음 그중 최대 3개를 선택해 추천 이유와 참고사항을 생성합니다. 검색 결과에 없는 ID나 중복 ID는 거절하며, 가격과 URL은 모델 응답이 아닌 원본 도서 데이터에서만 가져옵니다.

`OPENAI_API_KEY`를 Sites 비밀 환경변수에 연결하면 활성화됩니다. `OPENAI_MODEL` 기본값은 `gpt-5-mini`입니다. 키가 없으면 연결 대기 상태를 표시하며 가짜 AI 결과로 대체하지 않습니다. 입력 취향은 OpenAI에, 생성한 검색어는 네이버에 전송됩니다. OpenAI 요청은 `store:false`이며 앱은 추천 이력을 저장하지 않습니다. API 요청당 최대 2회 모델 호출, 입력 크기 제한, 프로세스 내 동시성 2개·분당 10회 제한을 적용합니다. 분산 전역 한도는 아닙니다.

현재 AI 키가 연결되지 않아 실제 모델 호출 검증은 대기 중입니다. 입력/후보 검증과 오작동 처리는 모의 응답 테스트로 확인합니다.

## 입력 없는 자동 추천

첫 방문부터 실제 도서 3권과 미리 작성한 AI 추천 이유를 표시합니다. 기본 목록은 소설·경제·과학이며, 최근 검색 최대 5개의 주제를 태그 규칙으로 매칭해 우선순위를 바꿉니다. `다른 책 보기`로 사전 선정한 8권을 순환합니다. 이 정렬은 브라우저 내 규칙 기반 처리이며 실시간 AI 추론이 아님을 화면에 표시합니다. 수집 가격은 7일 후 숨깁니다. 기존 실시간 AI 추천 입력 화면은 접힌 추가 옵션으로 유지합니다.

## 트렌드 기반 오늘의 추천

`GET /api/daily-picks`는 네이버 데이터랩의 동일한 최신 관측 주간 상대 검색량으로 분야를 정렬합니다. 현재 선정 도서가 있는 소설·경제 경영·과학에서 분야별 한 권씩 고르고, 한국시간 날짜로 분야 내 도서를 순환합니다. 후보가 없는 분야·과거 주간만 있는 분야는 제외합니다. 한 권뿐인 분야는 날짜가 바뀌어도 유지됩니다. 전 도서 대상 추천이나 실시간 판매순위가 아닙니다.

서버는 성공 결과를 한국시간 당일 동안 메모리에 캐시합니다. 첫 방문과 화면이 열린 동안 날짜 변경 시 자동 조회하며, 실패하면 기존 기본 추천임을 명시해 표시하고 1분 후 재시도합니다. 외부 정기 작업 없이 방문 시 갱신하는 방식입니다.

## 문장으로 책 찾기와 소개 수집

`scripts/collect-discovery.mjs`는 네이버 검색으로 찾은 YES24 상품 중 기존의 robots·판본·ISBN 검증을 통과하고 30자 이상 소개가 있는 상품을 수집합니다. ISBN으로 중복을 제거해 `data/discovery.json`에 저장하며 쿼리 사이 1.2초 대기, 검색당 최대 4개 상품 요청 제한을 유지합니다. 기존 자료를 보존하며 성공한 검색마다 파일을 원자적으로 저장합니다. 최초 112권을 수집했습니다. 상품 소개는 최대 1,000자이며 목차·본문은 미수집입니다. 새로 수집한 자료를 반영하려면 재배포가 필요합니다.

`/api/discovery?q=...&mode=situation|taste|purpose|memory`는 소개·제목·분야 문구와 사전 정의한 검색 특징을 매칭합니다. 상황·취향·목적·기억 탭을 제공하며 최대 8개 후보, 근거 발췌, 원문 링크를 보여줍니다. 참조한 책은 취향 검색에서 제외하고 일부 명시적 부정 조건(수식, 슬픔)을 처리합니다. 문장 전체를 이해하는 AI 의미 검색이나 임베딩 검색은 아니며 이 제한을 화면에 표시합니다. 모르는 특징이나 완독 시간은 생성하지 않습니다. 부정 조건이 원문에 없더라도 해당 특징이 없다고 보장하지 않습니다.

## 책과 함께 듣기

추천 카드, 문장 검색 결과, 도서 상세에 `이 책과 함께 듣기`를 추가했습니다. 핵심 추천 8권은 책별 조합을 사용하고 나머지는 분야·기본 연주 조합임을 구분합니다. 음악 4곡의 아티스트·레이블 공식 페이지를 확인해 연결하며 곡별로 2개 선택지를 제공합니다. 개인 감상에 따른 선정 이유이며 자동 감정 분석이나 집중력 효과를 주장하지 않습니다. 음원은 저장·자동 재생하지 않으며 YouTube Music의 곡명·아티스트 검색 결과를 엽니다. 직접 재생을 보장하는 링크가 아니며 검색 결과에서 음원을 선택합니다.
