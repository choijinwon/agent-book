# agent-book

도서 검색, ISBN 기반 가격 비교, 베스트셀러 트렌드 앱입니다. FIND / WEAR의 검색·필터·비교 흐름을 도서에 맞게 구성했습니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run dev
```

기본 주소: http://localhost:5173

```sh
npm test
npx tsc --noEmit
npm run build
```

## 제공 기능

- 제목·저자·ISBN 검색, 분야와 배송비 포함 예산 필터, 총액·제목 정렬
- 동일 ISBN13에 한해 출처별 가격 병합. 판본이 다르거나 ISBN이 없으면 별도 도서로 유지
- 배송비가 확인된 판매처의 상품가 + 배송비로 최적 총액 산출
- 최대 3권 선택 비교, 도서별 가격 상세, 서점 직접 검색
- 알라딘 국내도서 베스트셀러와 해당 목록의 분야별 구성
- 최근 검색 5개를 현재 브라우저에 저장, 개별 검색어 재사용 및 전체 지우기
- 명시적인 예시/실제 모드, 미연결·빈 결과·부분 실패·전체 실패 처리
- 모바일 대응 및 키보드 접근 가능한 탭·선택·비교 대화상자
- 선택적 WebMCP `search_books` 도구

## 실제 데이터 연결

`.env.example`의 이름에 맞춰 로컬에서는 `.dev.vars`에 값을 입력합니다. 배포 환경에서는 Sites의 서버 환경변수/비밀값 설정을 사용합니다. 키를 Git에 커밋하거나 브라우저에 전달하지 마세요.

| 변수 | 역할 |
| --- | --- |
| `ALADIN_TTB_KEY` | 알라딘 도서 검색·상품 가격·베스트셀러 |
| `NAVER_CLIENT_ID` | 네이버 도서 검색 |
| `NAVER_CLIENT_SECRET` | 네이버 도서 검색 인증 |

키를 설정한 뒤 서버를 재시작하고 상단에서 **실제 도서**를 선택합니다. API 키가 없는 상태에서도 예시 모드와 서점 검색 링크는 동작합니다. 예시의 도서·서점·가격·순위는 모두 가상 데이터입니다. 실패한 실제 조회를 예시 데이터로 대체하지 않습니다.

### 가격 및 트렌드의 범위

현재 실제 판매처 가격 API는 알라딘입니다. 네이버 책 API의 `discount`는 도서 가격 정보로 표시하며 개별 서점의 확정 견적으로 취급하지 않습니다. 교보문고·YES24는 직접 검색 링크를 제공합니다. 전 서점 실시간 최저가를 보장하지 않습니다.

현재 연동 API가 배송비를 제공하지 않으므로 실제 도서의 배송비와 최종 결제 총액은 **확인 필요**로 표시합니다. 무료 배송을 추측하지 않습니다. 배송비 미확인 상품은 총액 예산 필터에서 제외하며, 가격 정렬에서 마지막에 표시합니다. 쿠폰·회원 혜택·포인트를 현금 할인으로 합산하지 않습니다. 중고·전자책·다른 판본은 같은 가격 비교에 합치지 않습니다.

트렌드는 알라딘이 반환한 베스트셀러 순위의 단일 시점 조회이며, 조회 시간과 출처를 표시합니다. 과거 순위·변화율·전국 시장 점유율을 만들어 내지 않습니다. 각 API에서 최대 30건을 조회하며 전체 검색 결과의 최저가를 뜻하지 않습니다. 서버 메모리에 최대 100개의 결과를 60초 캐시합니다.

### API

- `GET /api/status`: 키 존재 여부만 반환. 실제 인증 성공 보장은 아님
- `GET /api/books?q=...`: 1~100자 검색, 출처별 부분 실패 표시
- `GET /api/trends`: 알라딘 국내도서 베스트셀러

알라딘/네이버 키가 없으면 503, 공급자 전체 실패는 502, 잘못된 검색어는 400을 반환합니다. 공급자 요청은 8초 제한이며 오류 메시지에 인증 정보를 포함하지 않습니다.

## 구조

- `app/page.tsx`: 검색·필터·비교·트렌드 화면
- `lib/books.ts`: 도서 모델, ISBN 정규화, 가격 계산, 예시 데이터
- `lib/providers.ts`: 서버 도서 API 어댑터와 부분 실패 처리
- `lib/api.ts`, `app/api/*`: Cloudflare Workers 서버 경로와 캐시
- `tests/`: 총액, ISBN 병합, URL 안전성, 공급자 계약 검증
- `.openai/hosting.json`: Sites 프로젝트 연결
